# TestFly Studio — AI Test Automation for VS Code

**TestFly Studio** brings autonomous AI test automation, Playwright MCP browser integration, and framework-native Java 21 test code generation to **Cursor**, **GitHub Copilot**, and **Claude Desktop**.

Zero Python. Zero setup headaches.

---

## ✈️ Key Capabilities

- 🤖 **Playwright MCP Integration:** Works seamlessly with the official Playwright MCP for ultra-fast live browser control and accessibility inspection.
- ⚡ **1-Click Multi-Assistant Setup:** Configures Playwright MCP and TestFly Bridge across Cursor, Claude Desktop, VS Code Native Copilot, and Claude Code with a single click.
- 🎯 **Action Cache Explorer:** Visual Webview panel to inspect, invalidate, and manage autonomous `act("Goal")` action plans frozen in `.testfly/action-cache.json`.
- 🩹 **AI Self-Healing Patch Reviewer:** Visual diff viewer to inspect and apply `.patch` remediations synthesized by TestFly's `AiHealingEngine` directly to your test code.
- ⚙️ **Visual testfly.yml Editor:** In-IDE editor for timeouts, parallel execution, and AI providers (Gemini, Claude, OpenAI).
- ☕ **TestFly Framework-Native Codegen:** Generates production-ready Java 21 tests (`BaseTest`, `BasePage`, `getByRole`, `assertThat`).
- 🏗️ **Project Scaffolding:** Instant scaffolding of Java 21 + TestFly 1.0.6 test suites.
- 📊 **Smart CI/CD Sharder:** Balances test loads across parallel CI nodes using LPT Bin-Packing.

---

## 🚀 Quick Start

1. Install this extension in VS Code.
2. Open the **TestFly Studio** sidebar on the Activity Bar.
3. Click **⚡ 1-Click Multi-Assistant MCP Setup** under Quick Actions.
4. Your AI assistant is now ready to drive real browsers and author TestFly Java test suites!
